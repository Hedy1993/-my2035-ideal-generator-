# 二次开发指南

本项目刻意保持"单文件"结构以便复制、修改、二次开发。

## 快速开始

```bash
git clone <本仓库地址>
cd my2035
# 直接双击 index.html 在浏览器打开
# 或本地启动一个静态服务
python -m http.server 8080
```

## 常见定制

### 1. 修改岗位模板

打开 `index.html`，找到 `TEMPLATES` 对象，编辑六类岗位的关键词词典和路线图内容。

### 2. 修改视觉风格

`index.html` 的 `<style>` 块集中了所有样式。可调整：

- 主题色：搜索 `#ffd76e`（金色高亮） / `#9fb8e8`（浅蓝辅文）
- 背景：搜索 `linear-gradient(160deg, #0a1633 0%, ...)`
- 字号 / 间距：搜索对应 px 值

### 3. 接入教师驾驶舱

将本仓库的 `index.html` 与一个 `teacher.html` 部署在同一域名下。`teacher.html` 通过 `localStorage` 读取学生数据并聚合可视化。

### 4. 替换分享卡片背景

把图片文件放在 `assets/` 目录，修改 `index.html` 中分享卡片 DOM 元素的 `background-image` URL。

### 5. 增加更多岗位路线模板

在 `TEMPLATES` 中追加新键值对即可，建议保持四步结构以保证视觉一致性。

## 部署

任何静态托管平台均可：

- GitHub Pages（推荐）
- Vercel / Netlify / Cloudflare Pages
- 学院内部静态服务器
- WorkBuddy CloudStudio 等
