# 技术说明

## 架构

单文件 SPA（Single Page Application），所有 HTML、CSS、JavaScript 均在 `index.html` 中。

```
index.html
├── <style>   —— 全部样式（约 180 行）
├── <body>    —— DOM 结构（约 60 行）
└── <script>  —— 应用逻辑（约 110 行）
    ├── 状态管理（填空值 / 路线图 / 卡片）
    ├── 岗位关键词识别与模板匹配
    ├── 路线图模板引擎（六类岗位）
    ├── 分享卡片 DOM 生成
    └── localStorage 留痕
```

## 关键设计

### 三要素句式校验

三个 input 元素绑定事件，实时拼接成完整句式。任一空未填时"生成"按钮禁用。

### 岗位关键词自动匹配

`index.html` 内置关键词词典，遍历用户输入的"岗位"字段，命中关键词即选中对应路线图模板：

```js
const TEMPLATES = {
  讲解: ['导游', '讲解', '...'],
  研学: ['研学', '教育', '...'],
  // ...
};
```

### 路线图模板引擎

每个模板定义四步（2026/2028/2031/2035），每步包含"个人目标"与"国家节拍"两个字段。生成时按用户输入替换占位符。

### 分享卡片导出

通过 DOM 生成一张固定宽高的卡片元素（背景图 + 用户三要素 + 二维码占位），长按即可保存。

### 本地留痕

每次生成时把 `{岗位, 行动, 国家需要, timestamp}` 写入 `localStorage['my2035_records']`。教师可在浏览器控制台导出 JSON。

## 性能

- 整页大小 < 20 KB（含 HTML+CSS+JS）
- 首屏渲染 < 100ms
- 移动端 60fps

## 浏览器兼容

- iOS Safari 14+
- Android Chrome 90+
- 桌面 Chrome / Edge / Firefox

## 安全

- 不采集、不上传任何个人信息
- 全部数据仅存浏览器 localStorage
- 无外部依赖、无第三方追踪脚本
