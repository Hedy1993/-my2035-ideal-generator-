# 我的2035 · 理想生成器（My 2035 · Ideal Generator）

> 一款纯前端的"理想生成器"网页应用，围绕"三要素句式 → 个性化路线图 → 分享卡片"三步，帮学生把"个人理想与国家需要相遇"这句话写出来、画出来、发出去。

> **在线访问**：<https://024695ae02d5498b897e4144592b312f.app.workbuddy.host/>

## 项目背景

本作品是山东旅游职业学院思政课教师（参赛教师本人）围绕《思想道德与法治》第二章第二节"坚定信仰信念信心"——课题"与2035年的自己对话"——自主开发的教学工具。

课堂上，学生扫描大屏上的二维码即可进入本应用，"人手一屏"完成：

1. **三要素句式填空**：`2035年，我在____（岗位·地点），用____（专业行动），服务____（国家需要）`
2. **一键生成"从今天到2035"四步个性化路线图**（按岗位关键词自动匹配内置六类岗位模板：讲解/研学/酒店/数字运营/规划/管理）
3. **一键生成分享卡片**（长按保存，可发班级群"让你的2035被看见"）

应用为"山东省2026年'人工智能+'示范课程评选"材料二"人工智能+课程实践成果"的**成果一**。

## 教学应用场景

详见 [`docs/教学应用.md`](docs/教学应用.md)。

- **第2课时·环节六**"践行生成·我的2035"——全班扫码进入生成器，人手一屏补全三要素句式，自动生成个性化路线图与分享卡片
- 生成的路线图随后交给即梦 AI 二次生成"2035年的我"画像，与课前作品形成"想象版—规划版"前后对比
- 应用内置六类岗位路线模板按学生岗位意向自动适配，实现大规模因材施教

## 技术特性

- **零依赖**：纯前端单页 HTML，无任何外部 JS/CSS 框架，**无需后端服务、无需数据库**
- **离线可用**：首次加载后断网仍可继续使用（生成行为数据仅本地留存）
- **移动优先**：响应式设计，适配手机竖屏，扫码即用
- **数据本地留痕**：所有生成数据仅存浏览器 localStorage，不上传任何个人信息
- **可记录可追溯**：教师可在驾驶舱查看全班生成数据
